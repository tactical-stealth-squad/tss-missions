# TSS missions

Arma 3 missions played by the Tactical Stealth Squad.

The TSS website reads this repository: every mission folder here shows up in the mission overview on the site, with its briefing and slot list, and can be picked for an operation. Problems found while playing are reported on the site and land here as issues.

- Adding or updating a mission: see [CONTRIBUTING.md](CONTRIBUTING.md).
- Reporting a problem: use the mission page on the site, or the "Problem report" form under Issues.
- An example to copy from: [`op_example.Stratis`](op_example.Stratis).
